# Iris Flower Classification

## Objective

To build a Machine Learning model that classifies Iris flowers into different species based on their measurements.

## Dataset

The Iris dataset contains measurements of:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target classes are:
- Setosa
- Versicolor
- Virginica

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Models Used

### Logistic Regression
Accuracy: 96.67%

### K-Nearest Neighbors (KNN)
Accuracy: 100%

## Evaluation

The models were evaluated using accuracy score and confusion matrix.

## Conclusion

The Machine Learning models successfully classified the Iris flower species. K-Nearest Neighbors achieved the highest accuracy of 100% on the test data.
