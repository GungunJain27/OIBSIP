# Car Price Prediction with Machine Learning

## Objective
To predict the selling price of used cars using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Vehicle Dataset from CarDekho

## Machine Learning Models
- Linear Regression
- Random Forest Regressor

## Evaluation Metrics
- MAE
- RMSE
- R² Score

## Project Steps
- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis
- Data Encoding
- Train-Test Split
- Model Training
- Model Evaluation
- Feature Importance Analysis
